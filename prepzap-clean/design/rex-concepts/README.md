# Fresh Rex SVG concepts

These are new standalone fox character studies responding to the supplied visual
references. They do not reuse the old Rex illustration, scholar costume, glasses,
cap or robe. The app component has deliberately not been changed.

- `01-tail-curl.svg`: compact, energetic silhouette with a curled tail.
- `02-sidekick.svg`: upright, asymmetric ears and a raised arm; recommended for
  expressive gesture animation after a silhouette is selected.
- `03-pocket.svg`: calm, seated silhouette with a folded tail.

Each is editable SVG, approximately 2.3KB, with named head, eyes, mouth, body,
arms and tail groups. These are concept drawings, not the completed animation
rig. The selected direction will next get separate eyelids, pupils, eyebrows,
ears and hands, followed by expression studies and reduced-motion-safe behavior.

`index.html` is a local comparison sheet; `review-sheet.png` is its browser render.
No brand palette changes, dependencies, app routes or deployed UI were modified.
